Terms used in this app
TM (Translation Memory)
Search past translations of similar or identical source text, so the same phrase doesn't get translated differently twice.
QA issue
An automatic check on your translation (repeated words, punctuation, spacing, length, mismatched numbers) flagged for a second look. It doesn't block saving.
Token / placeholder mismatch
Your translation is missing a game placeholder (like %1 or <tag>) that appears in the source text, or has one the source doesn't.
Glossary miss
This project has an approved translation for a term used in the source text, and your translation doesn't use it.
Lock
Someone else is actively editing this string or file right now. Locked entries are read-only until they're released.
Suggest
A string that's already translated can't be overwritten directly, so propose a replacement instead. The current translator or a reviewer can apply it.
Approve
A reviewer marking a translation as reviewed and correct. It doesn't change the text.
